# Notepad

Application de prise de notes développée avec **Next.js 14**, **TypeScript** et
**Tailwind CSS**.

> 🚧 **En cours de développement** — l'ossature Next.js (App Router) est en
> place ; les fonctionnalités de prise de notes sont en construction.

## Stack technique

- **Next.js 14** (App Router)
- **React 18**
- **TypeScript 5**
- **Tailwind CSS 3**

## Mise en route

Prérequis : Node.js 18+.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # build de production
npm run lint     # analyse ESLint
```
